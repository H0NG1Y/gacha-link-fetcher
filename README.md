# 鸣潮唤取链接获取器

一个 Windows 本地小工具，用于从《鸣潮》客户端日志中获取「唤取记录」链接，方便导入你信任的抽卡统计工具。

## 功能

- 自动检查常见的《鸣潮》安装目录
- 支持手动选择游戏目录
- 从 `Client.log` 和 WebView 的 `debug.log` 中读取最新记录链接
- 兼容当前客户端可能使用的日志混淆格式
- 一键复制链接到剪贴板
- 不联网、不上传账号资料、不修改游戏文件、注册表或文件权限

## 使用方法

1. 打开《鸣潮》，进入任意卡池。
2. 点击左下角的「唤取记录」，等待页面完全加载。
3. 双击 `鸣潮唤取链接获取器.exe`。
4. 点击「自动获取链接」，成功后点击「复制链接」。
5. 将链接粘贴到你信任的统计工具中。

如果程序未自动找到游戏，请点击「手动选择…」，选择包含 `Client` 文件夹的游戏目录后重试。

## 安全提示

唤取记录链接带有临时查询凭证。请不要将它发送给陌生人或公开发布；仅将其粘贴到你信任的统计服务中。
