## About

A local Windows utility that reads gacha-history links already generated by supported games, ready for import into a tracker you trust.

| Game | History page |
| --- | --- |
| Wuthering Waves | Convene History |
| Genshin Impact | Wish History |
| Honkai: Star Rail | Warp Records |
| Zenless Zone Zero | Signal Search Records |

> The tool does not call game APIs, upload account data, or modify game files, the registry, or system permissions.

## Download

Download the latest version from [GitHub Releases](https://github.com/lllusorysky/gacha-link-fetcher/releases/latest).

The newest local build is named `GachaLinkFetcher.exe`; GitHub Release assets include their version number.

## How to use

1. Enter any banner in the target game and open its matching history page.
2. Wait for the history page to finish loading.
3. Run the EXE and **select the target game** from the list.
4. Select **Automatically get link**, then **Copy link**.
5. Paste the link into a tracker you trust.

If the game is not found, use **Manually select…** and choose the actual game directory containing the game EXE or a `*_Data` folder.

## Features

- Checks common installation folders
- Reads the newest link from local logs or `webCaches`
- Supports manual game-directory selection
- Copies the link to the clipboard
- Supports common official launcher, WeGame, Steam, and Epic folders for Wuthering Waves
- Supports common miHoYo Launcher and HoYoPlay folders for miHoYo games

## Security

A gacha-history link contains a temporary query credential. Do not post it publicly or send it to strangers. Paste it only into a service you trust.

## FAQ

**No link was found?**
Open the history page in-game, wait for it to load, and try again. If it still fails, manually select the actual game directory.

**Does the tool upload account data?**
No. It only reads local log or cache files for the history link. It does not connect to the internet or modify game files.
